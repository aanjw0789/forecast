# Multi-Temporal Variability Forecast of Particulate Organic Carbon in the Indonesian Seas

This repository contains Python codes developed for the study:

Wahyudi, A. J., Febriani, F., & Triana, K. (2023).  
*Multi-temporal variability forecast of particulate organic carbon in the Indonesian seas*.  
Environmental Monitoring and Assessment, 195(3), 1–20.  
https://doi.org/10.1007/S10661-023-10981-9

## Overview

This repository provides a reproducible workflow for forecasting particulate organic carbon (POC) variability in the Indonesian seas using Seasonal Autoregressive Integrated Moving Average (SARIMA) models.

The workflow includes:

- Time-series preprocessing
- Seasonal decomposition
- Stationarity testing
- SARIMA model configuration and optimization
- Forecast generation
- Statistical model evaluation
- Temporal variability visualization

## Scientific Objective

The study aims to investigate and predict the temporal variability of particulate organic carbon in Indonesian marine systems using statistical time-series forecasting approaches.

The forecasting framework captures seasonal and interannual variability associated with monsoonal forcing and oceanographic processes in the Indonesian seas.

## Data and Variables

The workflow primarily focuses on:

- Particulate Organic Carbon (POC)
- Monthly time-series variability
- Seasonal dynamics
- Marine environmental variability

## Methods

The repository implements:

- SARIMA (Seasonal ARIMA) forecasting
- Time-series diagnostics
- Forecast validation metrics
- Visualization of observed and predicted POC dynamics

## Python Libraries

Main libraries used include:

- pandas
- numpy
- matplotlib
- statsmodels
- scikit-learn
